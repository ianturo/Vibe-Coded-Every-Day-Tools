# Tests a diferentes modelos de Inteligencia artificial

Este repositorio es un compendio de pruebas en las que reto a diferentes modelos a hacer pequeñas herramientas para el uso cotidiano

Cada prueba consiste en una Aplicacion Web que supla una necesidad real y sencilla (un convertidor de unidades, un generador de contraseñas, un traker de consumo de conbustible, etc.). El objetivo es ver cómo cada modelo interpreta el problema, estructura su código y resuelve la tarea, solo se publican tareas que considero funcional y util.

## ¿Cómo funciona?

Cada carpeta tiene una herramienta y en el Readme.md estara el prompmt usado
