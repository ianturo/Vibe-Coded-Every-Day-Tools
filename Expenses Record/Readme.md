# Aplicacion Registro de Gastos

## Prompt en Español

```text
Crea una aplicación web que permita llevar el registro de los gastos diarios, debe permitir crear categorías de los gastos y clasificar los gastos por categorías, debe mostrar el acumulado de gastos de los últimos 6 meses, el ultimo año y el consumo semanal, debe permitir exportar e importar los datos.
```
