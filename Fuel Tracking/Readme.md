# Fuel Consuption Tracker

## English Prompt
```text
Create a web application that uses a local database to track vehicle fuel consumption. It must prompt for each vehicle's license plate and initial odometer reading, followed by the number of gallons filled, the cost per gallon, and the distance traveled. For subsequent entries, it calculates the distance traveled based on the previous record's odometer reading (or the initial reading if no prior record exists). It must calculate miles per gallon and display a graph showing the last 10 fuel consumption and distance records. It should include an option to edit or correct previously entered data and allow for the export and import of recorded data.
```
